# تجربة قيّم على Windows

المتطلبات: Java 21، Maven 3.9+، Node.js 24 وnpm. من مجلد المشروع:

```powershell
.\scripts\start-demo.ps1
```

وفي نافذة ثانية:

```powershell
cd frontend
npm ci
npm run dev
```

افتح http://localhost:5200 واضغط «دخول تجريبي». لا يلزم إدخال اسم مستخدم أو كلمة مرور؛ يعرض الزر التحميل والخطأ عند تعذر الاتصال. يعمل الدخول المباشر فقط في وضع demo المعزول للقراءة. لا تُكشف DEMO_PASSWORD؛ ويمكن اختياريًا ضبطها محليًا للدخول التقليدي. عند عدم ضبطها ينشئ الخادم قيمة عشوائية في الذاكرة.

| السجل | العدد |
|---|---:|
| الجلسات | 6، ثلاث نشطة وثلاث مغلقة |
| المرشحون | 30، خمسة لكل قسم |
| المقيّمون | 8، منهم سارة لحساب العرض |
| إسنادات المرشحين | 90، ثلاثة لكل مرشح |
| التقييمات المرسلة أو المراجعة | 63 |
| المسودات | 6 |
| الإسنادات التي لم يبدأ تقييمها | 21 |
| المرشحون المكتملون / غير المكتملين / بانتظار البدء | 20 / 6 / 4 |
| حالات التباين | 4 |
| القرارات النهائية | 13 |

الأقسام: الموارد البشرية وتقنية المعلومات والمالية والتسويق والعمليات وخدمة العملاء. الأسماء الأولى طبيعية لكنها تمثل شخصيات وهمية بالكامل؛ لا توجد أرقام هواتف أو وثائق أو سير ذاتية حقيقية. البريد example.com أو example.invalid للعرض فقط. ملفات المرشحين تتضمن مؤهلات وخبرات ومسميات ومهارات وملاحظات وإجابات ودرجات مترابطة.

تُنشأ البيانات من DemoSeeder داخل قاعدة H2 في الذاكرة. يعيد تشغيل التطبيق الحالة الأصلية؛ تكرار استدعاء التهيئة في القاعدة نفسها لا يكرر السجلات. تتغير تواريخ الجلسات نسبة إلى أول الشهر الحالي، وتبقى السيناريوهات والدرجات ثابتة.

## سيناريوهات للفحص

- اختر المدير ثم قائمة المرشحين: ابحث عن نورة أو Noura، وصفِّ حسب القسم والجلسة والحالة والقرارات والدرجة. صدّر قائمة كاملة أو مصفاة ثم قارن عدد الصفوف مع العدد المعروض.
- افتح ملف نورة: يعرض القسم والمسمى والخبرة والمهارات والجلسة وثلاثة مقيّمين وتقييماتهم.
- مقارنة DEMO-002: خالد لديه تقييمات متباينة؛ عمر مسودة فقط، وفيصل لم يبدأ تقييمه. تظهر «—» و«لم يكتمل التقييم»، ولا تُحسب درجة صفرية.
- مقارنة DEMO-003: هيا لديها تقييم مرسل بدرجة 18 ومسودة وتقييم لم يبدأ. المتوسط 18 من مرسل واحد وعداد 1/3؛ النتيجة جزئية.
- اعرض التقارير الأربعة والرسوم، وبدّل الأدوار الأربعة من القائمة الجانبية. البيانات حقيقية داخل الديمو وليست أرقامًا ثابتة في الواجهة.

## التدريب المحلي

الإنشاء والحفظ والإرسال والرفع وتغيير القرارات غير متاحة في العرض؛ يوضح الشريط ذلك وتمنعها API. لاختبار الكتابة ببيانات وهمية أوقف الخادم ثم شغّل:

```powershell
.\scripts\start-demo.ps1 -Mode Practice
```

اختر كلمة مرور محلية خاصة عند الطلب، ثم سجّل يدويًا باسم demo. الدخول المباشر للزوار معطل في هذا الوضع، والخادم مقيد بـ loopback. تبقى إدارة الحسابات وكلمات المرور محظورة. جرّب تقييم فيصل DEMO-C006: ابدأ، أجب عن الأسئلة الستة، احفظ، أرسل، ثم راجع المدير والمقارنة. لا تنشر التدريب للزوار. جميع التغييرات تزول بإعادة التشغيل.

الذكاء الاصطناعي معطل في الديمو. لم تُنشأ ملخصات تدعي صدورها عن نموذج، ولا توجد ملفات CV حقيقية. اختبارات الإنتاج والقيود موثقة في VERIFICATION.md وSECURITY.md.
